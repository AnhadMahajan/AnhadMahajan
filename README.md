### <img src="https://media.giphy.com/media/hvRJCLFzcasrR4ia7z/giphy.gif" width="28"> About Me

I'm a third-semester Computer Science Engineering student specializing in Artificial Intelligence. My passion lies at the intersection of machine intelligence, interactive web development, and the Internet of Things (IoT). I love architecting solutions that not only think but also feel and respond to the real world.

<br>

- 🚀 **AI & Machine Learning:** Crafting emotion detection systems and building robust ML models. Certified in **Azure AI Fundamentals (AI-900)**.
- 💻 **Web Development:** Engineering dynamic and responsive user interfaces with **React, Tailwind CSS, and GSAP** for fluid animations.
- 🔗 **IoT & Automation:** Integrating hardware with the cloud using **Arduino and ThingSpeak** to create smart, real-time systems.
- 📚 **Currently Learning:** Deepening my knowledge of **Data Structures & Algorithms in Java** and exploring advanced **MLOps** practices.
